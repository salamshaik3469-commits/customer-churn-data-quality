# Customer Churn — Data Quality & Exploratory Analysis

This beginner-friendly project profiles, cleans and explores a customer churn dataset.

## Files
- `data/customer_churn_raw.csv`: synthetic raw sample containing quality issues.
- `data/customer_churn_cleaned.csv`: cleaned sample output.
- `notebooks/customer_churn_analysis.ipynb`: reproducible analysis notebook.
- `reports/data_quality_report.md`: cleaning decisions and limitations.

## Important
The original Edvyro-provided CSV was not attached in the chat. The included data is synthetic and for demonstration only. If Edvyro expects its supplied dataset, replace the raw CSV with that exact file and rerun the notebook before submission.
